# Week 5 - Spark Data Cleaning and Transformations

## Objective
Learn Apache Spark DataFrame operations by performing data cleaning, transformation, filtering, aggregation, and schema modifications using PySpark.

## Technologies Used

- Python
- Apache Spark (PySpark)
- Google Colab

## Dataset

- Sample - Superstore.csv

## Tasks Performed

- Initialized Spark Session
- Loaded CSV dataset into Spark DataFrame
- Removed duplicate records
- Checked and handled null values
- Applied filtering on Region and Category
- Performed aggregation using Count, Sum, Average, Minimum and Maximum
- Used GroupBy for category-wise analysis
- Renamed columns and modified data types
- Built a complete Spark data processing pipeline

## Learning Outcomes

- Spark DataFrame Fundamentals
- Data Cleaning
- Filtering Operations
- Aggregation Functions
- GroupBy Operations
- Schema Modifications
- Data Processing Pipeline
