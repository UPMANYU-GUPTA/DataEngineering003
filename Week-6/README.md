# Week 6 - Apache Spark Assignment

## Objective
Perform data processing using Apache Spark (PySpark) including reading CSV files, applying transformations, filtering data, modifying schema, handling null values, and saving processed data in CSV and Parquet formats.

## Technologies Used
- Python
- PySpark
- Apache Spark
- Jupyter Notebook

## Tasks Performed
- Created Spark Session
- Loaded CSV dataset
- Viewed Data Schema
- Counted Rows
- Selected Required Columns
- Filtered Sales Data
- Renamed Columns
- Cast Data Types
- Added New Column
- Handled Null Values
- Applied GroupBy Aggregation
- Saved Processed Data as CSV
- Saved Processed Data as Parquet
